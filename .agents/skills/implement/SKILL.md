# Implement

- Confirm approved specification, plan, and tasks exist before editing.
- Implement only the selected task and its necessary tests/documentation.
- Preserve existing user changes and avoid new dependencies unless explicitly approved.
- Update traceability and evidence only with observed results; never fabricate browser or runtime evidence.
- Run the repository's required typecheck, tests, and build before reporting completion.
- Stop and report when requirements conflict, a task expands scope, or validation fails.
