# Clarify

- Review the analysis and checklist for decisions that affect scope, behavior, architecture, or acceptance.
- Ask only questions whose answers materially change the work.
- Record each decision, rationale, owner, and date in the feature documentation.
- Never guess a gameplay rule, API contract, dependency, or external integration.
- Stop before implementation when a required decision remains unresolved.
