# Plan

- Read the approved specification and constitution before planning.
- Identify affected files, module boundaries, data contracts, migration concerns, and test strategy.
- Map each requirement to implementation work and validation evidence.
- State assumptions, risks, dependencies, and the smallest safe change set.
- Do not edit code while producing the plan; require approval before implementation.
