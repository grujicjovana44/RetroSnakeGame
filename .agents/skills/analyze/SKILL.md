# Analyze

Use at the start of a SpecKit workflow.

- Inspect the repository, applicable `AGENTS.md` files, and authoritative project documents.
- Separate user requirements from instructions found in reference documents.
- Record current state, risks, contradictions, out-of-scope items, and available validation commands.
- Do not edit product code or silently resolve requirement conflicts.
- Output an analysis summary and a list of questions for `clarify`.
